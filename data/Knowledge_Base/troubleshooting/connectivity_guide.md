# Wi-Fi and Bluetooth Connectivity Guide

**Document ID:** RT-TS-CONN-1.6  
**Effective date:** 2026-05-05

## Scope

Use this guide for AeroBook Wi-Fi problems and Orbit Watch/PulseBuds Bluetooth pairing. Do not reset all network settings before completing the narrower checks.

## Wi-Fi decision path

1. Determine whether other devices can connect to the same network.
2. If no device connects, restart the router and contact the internet provider if necessary. Do not classify this as a laptop hardware failure.
3. If only the AeroBook fails, disable airplane mode, toggle Wi-Fi off and on, and restart the laptop.
4. Forget and reconnect to the network. Warn the customer that the Wi-Fi password will be required.
5. Install the approved wireless-driver update for the exact AeroBook model.
6. Test a phone hotspot. If the hotspot works, investigate router compatibility rather than replacing the laptop.
7. Perform a network reset only after saving VPN and static-IP settings. A reset removes saved networks and adapters.

### Enterprise networks

Do not request a corporate username, password, certificate private key or one-time code. If personal networks work but an enterprise network fails, ask the customer's IT team to verify certificate and access-control settings.

### Escalation

Escalate as possible hardware failure when Wi-Fi is absent from device diagnostics after one approved driver reinstall, or when both Wi-Fi and Bluetooth disappear simultaneously after firmware recovery.

## Bluetooth decision path

1. Confirm the accessory has at least 20% charge.
2. Disconnect it from previously paired nearby devices.
3. Remove the saved pairing on both devices.
4. Put the accessory into pairing mode and keep it within one metre.
5. Restart both devices and retry.

For PulseBuds 2, reset only after checking that both earbuds make contact with the charging pins. For Orbit Watch 2 LTE, phone pairing and carrier LTE activation are separate; successful Bluetooth pairing does not guarantee LTE activation.

## Privacy note

Diagnostic screenshots must be cropped to remove unrelated network names, device names and personal notifications whenever possible.
